# OpsPlatform - Database Documentation

هذا المجلد يحتوي على كافة الأكواد المرجعية لقاعدة بيانات منصة إدارة العمليات الميدانية والعهد النقدية (**PostgreSQL / Supabase**).

---

## الملفات المتاحة

### 1. `schema.sql`
- **جداول النظام الأساسية:**
  - `users`: المستخدمون والأدوار الوظيفية (Admin, Ops Manager, Finance Officer, Field Officer, Viewer).
  - `petty_cash_funds`: صناديق وسلف العهد النقدية، حدود التخصيص، نسب الاستنزاف وتنبيهات السيولة.
  - `tasks`: المهام التشغيلية والميدانية وربطها بالعهد وقوائم الفحص (JSONB Checklists).
  - `expenses`: فواتير المشتريات والمصروفات الميدانية واحتساب ضريبة القيمة المضافة (5% VAT).
  - `settlements`: دورات التسويات المحاسبية وإقفال العهد ومطابقة الفواتير.
  - `audit_logs`: سجل التدقيق الأمني الزمني لكافة العمليات والحركات المالية.
- **الفهارس (Indexes):** لتسريع الاستعلامات والبحث.
- **سياسات الأمان (Row Level Security - RLS):** جاهزة للعمل على Supabase مباشرة.

### 2. `seed.sql`
- بيانات نموذجية أولية للمستخدمين، الصناديق، والمهام الميدانية لاختبار النظام مباشرة بعد البناء.

---

## خطوات إنشاء قاعدة البيانات في Supabase أو PostgreSQL

1. افتح **SQL Editor** في لوحة تحكم Supabase أو عميل PostgreSQL المفضل لديك (مثل pgAdmin أو DBeaver).
2. انسخ محتويات ملف `database/schema.sql` وشغّلها لإنشاء كافة الجداول والفهارس وسياسات الحماية.
3. انسخ محتويات ملف `database/seed.sql` لتعبئة البيانات التجريبية الأولية.
